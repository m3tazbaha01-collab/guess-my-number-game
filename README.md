#Guess My Number

A simple and interactive number guessing game built with HTML, CSS, and JavaScript.

The player attempts to guess a randomly generated secret number within a limited number of attempts. The game provides real-time feedback, tracks the player's score, and allows the player to restart the game at any time.

✨ Features
Random secret number generation
User input validation
Instant feedback for each guess
Indicates whether the guess is too high or too low
Score tracking
High-score tracking
Game-over state
Restart functionality
Responsive user interface
Clean and minimal game experience
🛠️ Built With
HTML5 — Semantic page structure
CSS3 — Styling, layout, and responsive design
JavaScript (ES6+) — Game logic and DOM manipulation
Prettier — Code formatting

🎮 How to Play
Enter a number in the input field.
Submit your guess.
The game tells you whether your guess is too high or too low.
Continue guessing while you have attempts remaining.
Try to achieve the highest possible score.
Use the Again! button to restart the game.
